# Week 4 - CIFAR-10 ANN vs CNN Learning Project

## Overview
This project demonstrates image classification on the CIFAR-10 dataset using two deep learning approaches:

1. Artificial Neural Network (ANN)
2. Convolutional Neural Network (CNN)

The objective is to understand why CNNs perform better than ANNs for image-based tasks by comparing their architecture, training process, and accuracy.

---

## Dataset

The project uses the CIFAR-10 dataset, which contains:

- 60,000 color images
- 10 classes
- 50,000 training images
- 10,000 testing images
- Image size: 32 × 32 × 3

### Classes
- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck
