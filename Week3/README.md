# Customer Intelligence System

## Objective
Developed an end-to-end Customer Intelligence System using classification, ensemble learning, and clustering techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Streamlit
- Matplotlib
- Seaborn

## Machine Learning Techniques
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- K-Means
- DBSCAN
- PCA

## Key Features
- Customer behavior analysis
- Campaign response prediction
- Customer segmentation
- Business intelligence insights

## Outcome
The system identifies customer purchasing behavior, predicts campaign responses, and creates customer segments for targeted business strategies.
